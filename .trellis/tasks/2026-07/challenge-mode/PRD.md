# 闯关模块（Challenge Mode）PRD

> 版本：v1.0 | 创建：2026-07-29 | 基于参考资料 + 用户确认设计决策

## 1. 产品概述

面向小学 1-5 年级学生，通过每日闯关方式完成语文、数学、英语学习任务。利用 AI 动态生成符合教材要求的练习题，结合教材 PDF 转换的基础题库，让学习变成游戏。

## 2. 核心设计决策（已确认）

| 维度 | 决策 |
|------|------|
| 失败处理 | 允许无限答错（答错给解析，完成所有题目即通关） |
| 年级设置 | 家长端设置，闯关时自动使用 |
| 奖励机制 | 龙币 + 经验 + 宝箱惊喜 |
| 题目缓存 | 数据库缓存（同一关重复玩直接用缓存） |
| 每日限制 | 每科每天1关，3科最多3关 |
| 题型 | 4选1选择题 |
| AI出题 | 同步调用，一次性生成整关题目 |
| Tab位置 | 新增独立Tab「🎯 闯关」 |
| 通关动画 | 全屏庆祝 |
| 预生成策略 | **50% 固定题库 + 50% AI 动态生成** |
| 教材利用 | PDF→Markdown→LLM生成基础题库+实时出题参考 |

## 3. 教材处理流程

### 3.1 教材概况
- 总计 327 本 PDF 教材
- 语文：统编版 12 本（1-6年级上下册）
- 数学：8个版本约 87 本
- 英语：多个版本约 228 本

### 3.2 PDF → Markdown 转换
- 工具：markitdown（已安装）
- 输出：每本教材转为结构化 Markdown
- 存储：`docs/教材/markdown/{学科}/{版本}/{年级}.md`
- 提取：章节结构、知识点、例题、练习题

### 3.3 知识图谱生成
- 从 Markdown 中提取知识树
- 五层模型：学科→年级→章节→知识点→能力
- 建立前置依赖关系
- 存储：`knowledge_points` 表

### 3.4 基础题库预生成
- 每学科每年级每章节预生成 20 题
- 使用 LLM 读取 Markdown 内容后出题
- 覆盖三大学科 × 5 年级 × 约 8 章节 × 20 题 = 约 2400 题
- 存储：`question_bank` 表

### 3.5 实时出题参考
- AI 实时出题时，传入对应章节的 Markdown 片段作为上下文
- 保证题目与教材同步
- 50% 基础题库 + 50% AI 动态生成，避免重复

## 4. 关卡难度设计

### 4.1 难度分布（每关10题）
| 顺序 | 难度 | 数量 | 说明 |
|------|------|------|------|
| 1-5题 | 简单 | 5题 | 基础识记 |
| 6-8题 | 中等 | 3题 | 知识应用 |
| 9-10题 | 挑战 | 2题 | 思维拓展 |

### 4.2 星级评价
| 正确率 | 星级 | 奖励倍数 |
|--------|------|----------|
| <60% | ❌ | 不通关，可重试 |
| 60-69% | ⭐⭐ | 1.0x |
| 70-79% | ⭐⭐⭐ | 1.0x |
| 80-89% | ⭐⭐⭐⭐ | 1.2x |
| 90-100% | ⭐⭐⭐⭐⭐ | 1.5x |

### 4.3 通关门槛
- 正确率 ≥ 60% 才算通关
- 通关解锁下一关
- 未通关可重试（消耗当日机会）
