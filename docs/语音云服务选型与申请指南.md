# 语音云服务选型与申请注册指南（ASR / TTS）

> 适用项目：作业小龙 · 语音聊天功能（Voice Chat）
> 编写日期：2026-07-22 ｜ 数据来源：各云厂官网定价页（截至 2026-07，价格可能变动，以官网实时为准）
> 目标：在 **2C2G 服务器跑 Hermes + Railway 托管前端** 的约束下，选出最省心、低成本、中文童声友好的 ASR/TTS 云服务，并给出可照做的注册申请步骤。

---

## 0. 先算一笔账：单孩用量到底多大？

语音功能针对一个 6–7 岁孩子，**低频使用**是关键假设：

| 指标 | 估算 | 年总量 |
|---|---|---|
| 语音对话轮次 | 20–50 次/天 | 7,300–18,250 次/年 |
| 每次 ASR 调用 | 1 次（短句 ≤60s） | 同上 |
| 每次 TTS 字符 | 小龙回复 ~80–150 字 × 约 3–5 句 | ~500–1,500 字/天 → **18–55 万字符/年** |

**结论**：年用量远低于各家免费额度。本项目几乎可以**零成本**跑语音，付费也仅在 ¥0–150/年 量级。所以选型重点不是"谁便宜"，而是：**童声识别准不准、流式延迟低不低、免费额度是不是"低用量真能用"、注册门槛高不高**。

### 1.3 Bonus：火山引擎（仅 TTS 强烈推荐做免费主力）

- 门槛：注册火山引擎账号 + 创建应用。

## 2. 推荐结论（结合本项目约束）

| 维度 | 推荐 | 理由 |
|---|---|---|
| **ASR 成本最优（单孩零成本）** | **百度智能云** | ASR **5万次永久免费**（个人认证，不过期），单孩 ~20–50 次/天可用约 1.4–2.7 年且永不失效；童声/流式略逊讯飞、方言少。TTS 亦 5万次永久免费。 |
| **ASR 童声最准（质量优先）** | **讯飞开放平台** | 中文童声识别最准、流式 partial 回显好、方言最多；但 ASR 免费仅 **1万次/一次性/3个月有效**（非每月、非永久），之后需付费（50万次¥1300/年）。TTS 每日 5 万字符免费，质量好。 |
| **要儿童音色 + 愿小额付费** | **腾讯云** | TTS 儿童/情感音色丰富、与微信生态近；但免费额度按月/季过期，低用量不划算，适合接受小额付费。 |
| **先试后买** | **阿里云** | 3 个月试用 + 便宜；CosyVoice 大模型需另购（不推荐，2C2G 用不上）。 |
| **TTS 免费主力/兜底** | **火山引擎**（仅 TTS） | 每月 500 万字符免费，音色好，可与讯飞 ASR 组合进一步降本。 |

**给本项目的最终建议（2026-07-22 定稿：ASR + TTS 全百度）**：
1. **ASR 主用百度**（5万次永久免费）：单孩低频场景几乎零成本，额度永不过期；识别率实测足够（百度近场普通话 98%）即用。端点已按官方文档校验为 `vop.baidu.com/server_api`（标准版，dev_pid=1537）。
2. **TTS 主用百度**：
   - 默认 `SPEECH_TTS_MODE=short` 走**短文本在线合成**（度丫丫 per=4，5万次永久免费，整句返回）；
   - 设 `stream` 走**流式文本在线合成**（童声 per=110 度小童，WebSocket 边合成边播放，实现「首句优先/边说边播」），配合后端 SSE(T3)+前端流式播放(T5) 达最低延迟。
3. **讯飞降级为「未来可选质量备选」（非主用）**：仅当孩子童声识别率实测不足时，再把 `SPEECH_ASR_PROVIDER=iflytek`（仅改环境变量，零代码改动）；但需注意其 ASR 免费仅 1万次/3个月有效、正式期约¥1300/年——这正是当初放弃讯飞主用的主因。
4. 无论选谁，**密钥只存 Railway 环境变量**，前端不经过任何密钥（详见第 4 节）。

## 3. 申请注册步骤（各家通用 + 逐家要点）

### 3.0 通用流程（四家都一样）
```
① 注册官网账号 → ② 实名认证（选「个人认证」即可，无需企业/备案域名）
   → ③ 开通「语音识别 / 语音合成」服务
   → ④ 控制台「创建应用 / 项目」→ 得到 AppID / APIKey / SecretKey / Token
   → ⑤ 把密钥填进 Railway 环境变量 → 后端调用
```
> ⚠️ **无需公众号、无需备案域名**：本项目走"前端录音→后端调云 API"，不是微信 JS-SDK `translateVoice`，所以不要求公众号资质。只有将来想用微信原生语音时才需要公众号（方案里已列为可选增强）。

### 3.1 讯飞开放平台（推荐）
1. 注册并登录 https://www.xfyun.cn → 实名认证（个人）。
2. 控制台 → 创建应用，得到 **APPID**。
3. 开通能力：**实时语音听写**（ASR）+ **在线语音合成**（TTS）。
4. 在「我的应用 → 服务管理」拿到该应用的 **APIKey** 和 **APISecret**（WebSocket 调用需 HMAC-SHA256 签名，官方有 Python 示例）。
5. 领取免费额度（听写个人 1万次 / 合成每日 5 万字符，控制台自动发放）。
6. 文档：https://www.xfyun.cn/doc/asr/voicedictation （听写）、https://www.xfyun.cn/doc/tts/online_tts（合成）。

### 3.2 百度智能云
1. 注册并登录 https://cloud.baidu.com → 实名认证（个人）。
2. 进入「语音技术」控制台，首次登录**自动发放永久免费额度**（ASR 5万次 / TTS 5万次）。
3. 创建应用，得到 **API Key** 与 **Secret Key**。
4. 调用前用 Key 换 **Access Token**（有效期约 30 天，服务端缓存复用）。
5. 文档：https://cloud.baidu.com/doc/SPEECH （短语音识别 / 语音合成）。

### 3.3 腾讯云
1. 注册并登录 https://cloud.tencent.com → 实名认证。
2. 开通「语音识别」「语音合成」；控制台创建密钥得到 **SecretId / SecretKey**（务必保管，仅显示一次）。
3. 安装 `tencentcloud-sdk-python`，用子账号密钥调用（建议建子账号限权）。
4. 注意：免费额度按月/季重置或过期，低用量请在控制台关注余量。
5. 文档：https://cloud.tencent.com/document/product/1093（ASR）、/1073（TTS）。

### 3.4 阿里云
1. 注册并登录 https://www.aliyun.com → 实名认证。
2. 开通「智能语音交互」，新用户 **3 个月免费试用**（2 并发）。
3. 控制台创建项目得到 **AppKey**；用 RAM 账号 **AccessKey** 换 Token（24h 有效，SDK 自动刷新）。
4. 付费升级：一句话识别 30千次 ¥100/年起。
5. 文档：https://help.aliyun.com/zh/isi/（智能语音交互）。

### 3.5 火山引擎（仅 TTS 备选）
1. 注册 https://www.volcengine.com → 实名。
2. 控制台创建应用，开通「语音合成 TTS」，得到 AK/SK。
3. 每月 500 万字符免费额度自动发放。
4. 文档：https://www.volcengine.com/docs/6561（TTS）。

## 4. 密钥安全管理（必须）

- 所有 **AppID / APIKey / SecretKey / Token** 只存 **Railway 环境变量**（如 `XF_ASR_APPID`、`XF_ASR_APIKEY`、`XF_ASR_APISECRET`、`XF_TTS_APPID`…），**绝不下发前端、不写进前端代码、不进 git**。
- 前端只与同源后端（`/api/chat/voice`、`/api/chat/tts`）通信，杜绝 CORS / 密钥泄露。
- 建议用子账号/受限密钥；定期轮换。
- `requirements.txt` 如需新增 SDK（如 `tencentcloud-sdk-python`），独占一行加入。

---

## 5. 与实现方案的衔接

- 后端 `chat_proxy.py` 的 `transcribe_audio()` / `synthesize_speech()` 用**可插拔接口**实现：先按你选定的云厂接入，其余家作为兜底分支。
- 拿到密钥后，把环境变量配进 Railway，即可联调（见计划文件 T1/T2）。
- 若暂未申请到密钥，后端可先返回友好降级（文字模式），不影响前端框架开发（计划 T3/T4/T5/T6 不依赖密钥）。
