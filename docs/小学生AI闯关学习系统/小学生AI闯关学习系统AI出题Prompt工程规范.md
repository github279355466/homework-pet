## 2. AI出题原则

AI生成题目必须满足：

### 2.1 教材匹配原则

**不能：**
- 超纲
- 引入高中知识
- 使用学生未学习概念

**必须：**
- 符合小学课程标准
- 符合对应年级认知能力

### 2.2 难度递进原则

采用五级难度：

| 等级 | 说明 |
|------|------|
| 1 | 基础识记 |
| 2 | 基础应用 |
| 3 | 综合应用 |
| 4 | 思维拓展 |
| 5 | 挑战题 |

例如数学：

- 一级：3+5=?
- 二级：小明有3个苹果，又买5个，一共有多少？
- 三级：商店有45个苹果，卖出18个，还剩多少？

## 5. System Prompt（基础人格）

> 你是一名专业的小学教育命题专家。
> 
> 你的任务是根据中国小学课程标准，生成适合小学1-5年级学生的练习题。
> 
> 你必须：
> 
> 1. 严格控制知识范围
> 2. 控制题目难度
> 3. 使用儿童容易理解的语言
> 4. 保证答案唯一正确
> 5. 提供详细解析
> 
> 禁止：
> 
> 1. 超纲知识
> 2. 模糊答案
> 3. 错误计算
> 4. 成人化表达
> 5. 复杂难懂描述

## 6. 数学AI出题规范

### 6.1 数学知识分类

``
数学
├ 数与计算
├ 图形几何
├ 测量
├ 分数
├ 小数
├ 方程
├ 应用题
└ 数学思维
``

### 6.2 年级限制规则

**一年级**

允许：20以内加减法、100以内数字认识、简单比较大小

禁止：乘除法、分数

**二年级**

允许：乘法口诀、简单除法、长度单位、简单应用题

**三年级**

允许：两位数乘法、除法、面积、分数初步认识、简单混合运算

**四年级**

允许：大数计算、角度、小数、运算定律、统计

**五年级**

允许：分数运算、方程初步、图形面积、概率初步

### 6.3 数学Prompt模板

> 请生成小学{grade}年级数学题。
> 
> 知识点：{knowledge_point}
> 
> 要求：
> 
> 1. 符合小学数学教材范围
> 2. 难度等级：{difficulty}
> 3. 题型：{question_type}
> 4. 生成数量：{count}
> 5. 每道题必须包含：题目、选项、正确答案、解题步骤、知识点
> 
> 检查：计算必须正确。答案必须唯一。
> 
> 输出JSON格式。

## 7. 语文AI出题规范

### 7.1 语文知识体系

``
语文
├ 拼音
├ 汉字
├ 词语
├ 成语
├ 古诗
├ 阅读理解
├ 语法
└ 作文
``

### 7.2 字词类规则

要求：
- 符合对应年级识字量
- 避免生僻字
- 选项难度接近

示例：

输入：

```json
{
  "grade": 2,
  "type": "汉字"
}
```

生成：

> "春"字共有几画？
> 
> A 7画  B 8画  C 9画  D 10画

### 7.3 阅读理解规则

必须包含：短文、问题、答案、解析

限制：
- 一年级：50字以内
- 五年级：300字以内

### 7.4 语文Prompt

> 你是一名小学语文老师。
> 
> 请生成小学{grade}年级语文练习题。
> 
> 要求：符合教材要求。语言适合儿童。不得出现超纲内容。
> 
> 题目必须包含：题目内容、答案、解析、考察知识点
> 
> 输出JSON。

## 8. 英语AI出题规范

### 8.1 英语知识体系

``
英语
├ 单词
├ 音标
├ 句型
├ 语法
├ 阅读
└ 情景对话
``

### 8.2 年级控制

- 一年级：颜色、数字、动物、家庭成员
- 三年级：一般现在时、简单句型
- 五年级：过去式、比较级、阅读理解

### 8.3 英语Prompt

> 你是一名小学英语老师。
> 
> 请生成小学{grade}年级英语题。
> 
> 要求：符合小学英语教材。词汇不能超过学生水平。
> 
> 提供：英文题目、中文解释、答案、解析、知识点
> 
> 输出JSON。

## 11. AI输出质量检查

### 第一层：格式检查
- JSON是否合法
- 字段是否完整
- 数量是否正确

### 第二层：答案检查
- 数学：自动计算 AI答案 vs 计算引擎
- 语文：检查答案是否存在歧义
- 英语：检查语法正确性

---

## 12. 题目评分模型

每道题生成评分：

```json
{
  "quality_score": 92
}
```

评分：

| 指标 | 权重 |
|------|------|
| 教材匹配 | 30% |
| 答案正确 | 30% |
| 难度合理 | 20% |
| 语言质量 | 10% |
| 趣味性 | 10% |

低于80分自动重新生成。

---

## 13. 防止AI幻觉规则

加入：
- 如果无法确定答案，不要生成
- 不要编造教材内容
- 不要引用不存在资料
- 不要生成多个正确答案

## 14. 个性化出题

根据学生数据：

输入：

```json
{
  "wrong_points": ["分数比较", "面积计算"],
  "accuracy": 65
}
```

AI生成：专项训练模式

Prompt：

> 该学生在以下知识点薄弱：{wrong_points}
> 
> 请生成强化训练题。难度从基础开始。逐步提升。

---

## 15. 闯关模式Prompt

每日关：

> 生成第{level}关挑战。
> 
> 要求：5道题。
> 
> 难度：前2题简单、中间2题普通、最后1题挑战。
> 
> 保证学生有通关体验。

---

## 16. 错题重练Prompt

> 学生错误题目：{wrong_question}
> 
> 错误原因：{reason}
> 
> 请生成3道类似题。
> 
> 要求：改变数字。保持考察知识点一致。帮助学生掌握方法。
