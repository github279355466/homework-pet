# 《小学生 AI 闯关学习系统整体方案》

文档版本：V1.0

---

## 一、系统总体定位

### 产品名称（暂定）

小学生 AI 闯关学习系统

### 定位

面向小学 1-5 年级学生，通过每日闯关方式完成语文、数学、英语学习任务，利用 AI 动态生成符合教材要求的练习题，让学习变成游戏。

---

## 十三、AI 出题规则设计（核心）

### 总规则 Prompt

发送给大模型：

> 你是一名小学数学命题专家。
> 
> 你的任务：根据中国小学教材标准生成练习题。
> 
> 要求：
> 
> 1. 适合小学三年级学生
> 2. 符合数学课程标准
> 3. 难度等级：中等
> 4. 题型：选择题
> 5. 数量：5题
> 6. 每题必须包含：题目、选项、正确答案、解析、知识点
> 7. 禁止：超纲知识、复杂计算、错误答案
> 8. 语言：儿童友好

---

## 十四、数学出题规则

### 参数

```json
{
  "subject": "数学",
  "grade": 3,
  "type": "选择题",
  "difficulty": 2
}
```

### 规则：

- 小学1年级：数字≤100
- 小学2年级：数字≤1000
- 小学3年级：乘除法、简单应用题
- 小学5年级：分数、小数、面积、方程初步

---

## 十五、语文出题规则

类型：

``
拼音、字词、成语、阅读理解、古诗、作文
``

> 要求：成语必须来自小学教材范围。

## 十六、英语出题规则

类型：

``
单词、音标、句型、阅读、语法、听力
``

规则：

- 一年级：apple、cat、dog
- 五年级：一般过去时、比较级、阅读理解

## 十七、AI 返回结构化 JSON

要求模型必须返回：

```json
{
  "level": 18,
  "subject": "数学",
  "questions": [
    {
      "id": 1,
      "type": "single_choice",
      "question": "3×5等于多少？",
      "options": ["10", "15", "20", "25"],
      "answer": "B",
      "analysis": "3×5表示5个3相加",
      "knowledge": "乘法基础",
      "difficulty": 1
    }
  ]
}
```

## 十八、题目质量控制

不能完全相信 AI。

增加审核层：

### 第一层：格式检查
- JSON是否合法
- 字段是否完整

### 第二层：数学验证
调用计算服务：

例如：
- AI：23+35=59
- 系统：23+35=58 → 拒绝

### 第三层：难度检测
AI评分：小学三年级 难度 1-5，目标 2

## 二十一、AI题库生成策略

不要实时全部生成。

推荐：混合模式

``
提前生成: 10000关
+ 实时生成: 个性化错题
``

例如：

系统发现学生分数应用题错误率80% → AI生成专项训练5关

## 二十二、进一步增强功能

### 1. AI 学习助手
- 学生：我不会
- AI：提示：先看个位数字，再计算十位

### 2. AI 自动调整难度
- 连续5题正确 → 提高难度
- 连续错误 → 降低难度

### 3. 家长端
- 查看：孩子今天数学8题，正确率90%，薄弱：分数比较
