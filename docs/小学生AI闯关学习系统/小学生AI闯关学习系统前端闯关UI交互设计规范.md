# 《小学生AI闯关学习系统 前端闯关UI交互设计规范》

文档版本：V1.0

| 项目 | 内容 |
|------|------|
| 文档名称 | 前端闯关UI交互设计规范 |
| 目标平台 | Web / 小程序 / App / 平板 |
| 设计参考 | Duolingo、游戏化学习App、RPG成长系统 |
| 核心理念 | 学习过程游戏化、反馈即时化、成长可视化 |
| 目标用户 | 小学1-5年级学生 |

---

## 1. 设计理念

### 1.1 核心原则

- **游戏化学习**：将学习过程包装为冒险游戏
- **即时反馈**：每道题立即给出反馈
- **成长可视化**：经验、等级、成就一目了然
- **奖励驱动**：龙币、宝箱、皮肤等激励系统

### 1.2 设计参考

- Duolingo：路径式学习地图
- 游戏化学习App：任务/谜题推进学习
- RPG成长系统：等级、装备、成就

---

## 23. 前端数据接口设计

### 23.1 获取每日任务

```
GET /api/task/today

返回：
{
  "level": 18,
  "subject": "数学",
  "reward": 50
}
```

### 23.2 获取关卡

```
GET /api/level/{id}

返回：
{
  "title": "乘法挑战",
  "questions": 5
}
```

### 23.3 提交答案

```
POST /api/question/check

参数：
{
  "questionId": 1001,
  "answer": "B"
}

返回：
{
  "correct": true,
  "coin": 10,
  "analysis": "..."
}
```

### 24.1 完整流程

``
进入首页 → 点击今日任务 → 进入关卡介绍 → 开始挑战 → 加载AI题目 → 答题 → 即时反馈 → 完成5题 → 计算奖励 → 展示动画 → 解锁下一关 → 更新成长数据
