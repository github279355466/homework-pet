# AI自动生成知识图谱规范（Knowledge Graph Generation Specification）

文档版本：V1.0

**适用于：**
- 小学生 AI 闯关学习系统
- AI 自动出题系统
- 个性化学习推荐系统
- 错题诊断系统
- 学习路径规划系统

---

## 1. 知识图谱定位

知识图谱是整个 AI 教育系统的核心基础设施。

它解决：AI 不知道"小学三年级数学应该学什么、先学什么、后学什么"的问题。

### 没有知识图谱：

``
学生: 三年级
    ↓
AI: 随机生成数学题
``

容易出现：超纲、难度错误、知识点跳跃、重复训练

### 有知识图谱：

``
学生: 三年级
    ↓
知识地图
    ↓
当前学习节点
    ↓
AI生成匹配题目
``

---

## 2. 知识图谱总体结构

采用五层模型：

``
学科 Subject
    ↓
年级 Grade
    ↓
章节 Chapter
    ↓
知识点 Knowledge Point
    ↓
能力 Skill
``

例如：

``
数学
 └── 三年级
      └── 乘法
           └── 两位数乘一位数
                ├ 会计算
                ├ 会列式
                ├ 会解决应用题
``

---

## 3. 知识图谱数据模型

### 3.1 Subject（学科）

```json
{
  "id": "math",
  "name": "数学"
}
```

### 3.2 Grade（年级）

```json
{
  "id": "math_grade3",
  "subject": "数学",
  "grade": 3
}
```

### 3.3 Chapter（章节）

```json
{
  "id": "math_g3_ch05",
  "name": "乘法",
  "semester": "上册",
  "order": 5
}
```

### 3.4 Knowledge Point（知识点）

核心节点：

```json
{
  "id": "kp_30001",
  "name": "两位数乘一位数",
  "grade": 3,
  "difficulty": 2,
  "parent": "乘法"
}
```

---

## 4. 知识点完整模型

每个知识点需要：

```json
{
  "id": "kp_math_001",
  "name": "两位数乘一位数",
  "subject": "数学",
  "grade": 3,
  "chapter": "乘法",
  "difficulty": 2,
  "description": "掌握两位数与一位数相乘的方法",
  "prerequisite": ["乘法口诀"],
  "next": ["两位数乘两位数"],
  "skills": ["计算", "应用"]
}
```

---

## 5. 知识点关系模型

知识不是平面的，需要建立关系。

### 5.1 前置关系

例如：

``
乘法口诀
    ↓
一位数乘法
    ↓
两位数乘一位数
    ↓
两位数乘两位数
``

数据库：

```json
{
  "from": "乘法口诀",
  "relation": "PRE_REQUIRE",
  "to": "两位数乘一位数"
}
```

### 5.2 相似关系

例如：面积计算 ≈ 周长计算

用于：推荐练习

### 5.3 易错关系

例如：分数比较 容易错误: 分母越大数字越大

用于：生成纠错题

---

## 6. 知识点能力模型

不要只记录"会不会"，需要：

``
知识 → 能力 → 熟练度
``

例如：

知识点：分数加法

能力拆分：

| 能力 | 等级 |
|------|------|
| 认识分数 | 1 |
| 同分母计算 | 2 |
| 异分母计算 | 3 |
| 应用题 | 4 |

## 9. AI知识抽取Prompt规范

### System Prompt

> 你是一名小学课程知识体系专家。
> 
> 你的任务：从教材内容中抽取结构化知识图谱。
> 
> 要求：
> 
> 1. 按学科、年级、章节组织
> 2. 提取最小知识单元
> 3. 建立知识依赖关系
> 4. 标注学习难度
> 5. 标注学生能力要求
> 
> 禁止：
> 
> 1. 添加教材不存在内容
> 2. 合并不同知识点
> 3. 删除关键知识点
> 
> 输出JSON格式。

## 13. 知识掌握度模型

推荐使用：Knowledge Tracing

模型：

``
学生能力 + 历史答题 + 错误类型 → 知识掌握概率
``

简单版本公式：

``
Mastery = 正确率×0.6 + 最近表现×0.3 + 学习次数×0.1
``

## 14. 知识图谱数据库设计

### Neo4j模型

**节点：**
- (:Subject)
- (:Grade)
- (:Chapter)
- (:Knowledge)
- (:Skill)
- (:Question)
- (:Student)

**关系：**
- Subject HAS Grade
- Grade HAS Chapter
- Knowledge REQUIRE Knowledge
- Question TEST Knowledge

### 示例：

``
(乘法口诀) REQUIRE ↓ (两位数乘一位数) TEST ↓ (题目001)
``

## 18. 知识图谱质量审核

### 自动检查

**完整性：** 每个知识点是否有前置知识、练习题、难度

**合理性：** 五年级知识不能依赖六年级知识

**冲突检测：** 例如错误：分数 前置: 方程 → AI发现关系异常 → 重新审核

## 20. 推荐实现方案

### MVP阶段

不要一开始做复杂知识图谱。

建议：MySQL + JSON知识树 + 向量数据库

结构：
- knowledge.json
- question_bank
- student_profile

### 后期升级

采用：
- Neo4j 图数据库
- Milvus 向量数据库
- RAG知识检索
- AI Agent自动维护

---

## 结论

对于"小学生AI闯关学习系统"，知识图谱应该承担：

- 决定学什么（知识范围）
- 决定顺序（学习路径）
- 决定难度（难度递进）
- 决定练什么（题目匹配）
- 决定补什么（错题诊断）
