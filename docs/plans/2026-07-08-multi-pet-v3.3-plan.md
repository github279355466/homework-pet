# 作业小龙 v3.3 多宠物系统 - 实施计划

> **For Hermes:** 使用 subagent-driven-development 技能按任务逐个实施。每个任务都遵循 TDD 循环。

**Goal:** 在现有单宠物作业小龙系统上增加多宠物领养/切换功能，采用混合模式（金币/成就共享，饱腹/心情/经验/亲密度独立），7 种物种，AI 生图资源，无领养上限，成就解锁自动发放。

**Architecture:** 双表拆分 - `pet` 表（id=1）保留为全局档案（金币/连续打卡/数学连续），新建 `pet_collection` 表存个体宠物（exp/hunger/mood/bond/status 独立），新建 `species_catalog` 表存物种目录。引入 `sync_active_pet_mirror()` 兼容层让 50+ 处旧 `WHERE id=1` 代码无需重写即可工作。冻结式切换：未激活宠物 `is_frozen=1` 不衰减，调度器仅作用于激活宠物。

**Tech Stack:** FastAPI 0.109 + SQLite + Jinja2 单页前端 + Python 3.12。测试用 `fastapi.testclient.TestClient` + `HOMEWORK_PET_DB_PATH` 环境变量隔离测试 DB。图片用 FLUX 2 Klein 9B 生成 PNG。

**项目约束**（来自 CLAUDE.md）：
- `app/homework_pet.db` 是生产数据，禁止直接修改，测试必须用 `HOMEWORK_PET_DB_PATH` 切换
- 推送 `main` 分支即触发 Railway 部署，启动命令 `python app/main.py`
- `main.py` 末尾 `port=int(os.environ.get("PORT", 5000))` 必须保留
- 前端单页 `app/templates/index.html`（~3243 行），后端单文件 `app/main.py`（~2141 行）
- 静态图片压缩 256×256 PNG 透明背景

**最终决策**（用户确认）：
- 同物种**不可**重复领养（每物种限 1 只）
- 扭蛋已领养的物种**不参与**抽选
- 第一版完整 **7 种**：龙/猫/兔/狐/独角兽/凤凰/熊猫
- 图片用 **AI 生图**（FLUX 2 Klein 9B）
- **无领养上限**
- **不做放生功能**
- 成就解锁宠物**自动发放**

```python
# app/migrations/v3.3_multi_pet.py
"""v3.3 单宠物 -> 多宠物数据迁移（幂等，可重复执行）"""
import logging

logger = logging.getLogger("homework-pet")

def migrate_single_to_multi_pet(conn):
    """把旧 pet 表数据迁移到 pet_collection，并设置 active_pet_id"""
    cur = conn.cursor()

    # 1. 确保物种目录有 'dragon'
    cur.execute("""
        INSERT OR IGNORE INTO species_catalog
            (id, name, icon, desc, base_price, rarity, acquisition_methods, stage_image_root, sort_order, enabled)
        VALUES ('dragon', '龙', '🐲', '经典陪伴小龙', 0, 'common', 'initial', '/static/species/dragon', 1, 1)
    """)

    # 2. 读取旧 pet 表数据
    old = cur.execute("SELECT * FROM pet WHERE id = 1").fetchone()
    if not old:
        return {"migrated": False, "reason": "no pet row"}

    # 3. 检查是否已迁移（避免重复）
    existing_count = cur.execute("SELECT COUNT(*) FROM pet_collection").fetchone()[0]
    if existing_count > 0:
        # 已迁移，仅确保 active_pet_id 字段一致
        if not old['active_pet_id']:
            first = cur.execute("SELECT id FROM pet_collection ORDER BY id LIMIT 1").fetchone()
            if first:
                cur.execute("UPDATE pet SET active_pet_id = ? WHERE id = 1", (first['id'],))
        return {"migrated": False, "reason": "already migrated"}

    # 4. 读取旧皮肤设置
    skin_id = 'default'
    cs = cur.execute("SELECT value FROM parent_settings WHERE key = 'current_skin'").fetchone()
    if cs and cs['value']:
        skin_id = cs['value']

    # 5. 创建第一只宠物（继承旧 pet 的所有个体属性）
    cur.execute("""
        INSERT INTO pet_collection
            (species_id, skin_id, name, exp, hunger, mood, bond, status, runaway_until,
             acquired_at, acquisition, is_frozen, last_decay_date)
        VALUES ('dragon', ?, ?, ?, ?, ?, ?, ?, ?, ?, 'initial', 0, ?)
    """, (
        skin_id,
        old['name'] or '作业小龙',
        old['exp'],
        old['hunger'],
        old['mood'],
        old.get('bond', 50) if 'bond' in old.keys() else 50,
        old['status'],
        old['runaway_until'],
        old.get('created_at'),
        old.get('last_decay_date'),
    ))
    new_pet_id = cur.lastrowid

    # 6. 设置 active_pet_id
    cur.execute("UPDATE pet SET active_pet_id = ? WHERE id = 1", (new_pet_id,))

    logger.info(f"[v3.3-migrate] 已迁移 pet id=1 -> pet_collection id={new_pet_id} (skin={skin_id})")
    return {"migrated": True, "new_pet_id": new_pet_id}
```

### Task 1.6：实现 sync_active_pet_mirror() 兼容层

**Objective:** 把激活宠物的属性同步到 pet 表镜像字段，让旧代码继续工作

**Files:**
- Create: `app/pet_helpers.py`（多宠物辅助函数集中存放）

**Step 1:** 创建辅助模块

```python
# app/pet_helpers.py
"""v3.3 多宠物系统辅助函数"""
import logging
from database import get_db_connection

logger = logging.getLogger("homework-pet")


def get_active_pet_id(conn):
    """获取当前激活宠物的 ID"""
    row = conn.execute("SELECT active_pet_id FROM pet WHERE id = 1").fetchone()
    if not row or not row['active_pet_id']:
        # 兜底：取第一只
        first = conn.execute("SELECT id FROM pet_collection ORDER BY id LIMIT 1").fetchone()
        if first:
            conn.execute("UPDATE pet SET active_pet_id = ? WHERE id = 1", (first['id'],))
            return first['id']
        return None
    return row['active_pet_id']


def get_active_pet_row(conn):
    """获取激活宠物的完整行（pet_collection）"""
    pid = get_active_pet_id(conn)
    if not pid:
        return None
    return conn.execute("SELECT * FROM pet_collection WHERE id = ?", (pid,)).fetchone()


def sync_active_pet_mirror(conn):
    """把激活宠物的属性同步到 pet 表镜像字段（兼容旧代码）"""
    pid = get_active_pet_id(conn)
    if not pid:
        return
    active = conn.execute("""
        SELECT exp, hunger, mood, bond, status, runaway_until, name, skin_id
        FROM pet_collection WHERE id = ?
    """, (pid,)).fetchone()
    if not active:
        return
    conn.execute("""
        UPDATE pet SET
            exp = ?, hunger = ?, mood = ?, bond = ?,
            status = ?, runaway_until = ?, name = ?
        WHERE id = 1
    """, (active['exp'], active['hunger'], active['mood'], active['bond'],
          active['status'], active['runaway_until'], active['name']))
    logger.debug(f"[v3.3-mirror] synced pet_collection id={pid} -> pet id=1")


def update_active_pet(conn, exp_delta=0, hunger_delta=0, mood_delta=0, bond_delta=0,
                     status=None, runaway_until=None, set_hunger=None, set_mood=None,
                     set_bond=None, set_exp=None):
    """更新激活宠物的属性（增量或绝对值）"""
    pid = get_active_pet_id(conn)
    if not pid:
        return None

    sets = []
    args = []
    if exp_delta:
        sets.append("exp = exp + ?")
        args.append(exp_delta)
    if hunger_delta:
        sets.append("hunger = min(100, max(0, hunger + ?))")
        args.append(hunger_delta)
    if mood_delta:
        sets.append("mood = min(100, max(0, mood + ?))")
        args.append(mood_delta)
    if bond_delta:
        sets.append("bond = min(100, max(0, bond + ?))")
        args.append(bond_delta)
    if set_exp is not None:
        sets.append("exp = ?")
        args.append(set_exp)
    if set_hunger is not None:
        sets.append("hunger = ?")
        args.append(set_hunger)
    if set_mood is not None:
        sets.append("mood = ?")
        args.append(set_mood)
    if set_bond is not None:
        sets.append("bond = ?")
        args.append(set_bond)
    if status:
        sets.append("status = ?")
        args.append(status)
    if runaway_until is not None:
        sets.append("runaway_until = ?")
        args.append(runaway_until)

    if not sets:
        return None

    sets.append("updated_at = CURRENT_TIMESTAMP")
    args.append(pid)
    sql = f"UPDATE pet_collection SET {', '.join(sets)} WHERE id = ?"
    conn.execute(sql, args)
    # 同步镜像
    sync_active_pet_mirror(conn)
    return pid
```

```python
    sync_active_pet_mirror(conn)
    conn.commit()
    conn.close()
```

```python
        "pet_id": pet_id
    }
```

```python
@app.post("/api/pets/gacha")

    """扭蛋抽取（已领养的不参与）"""
    if pool not in GACHA_POOLS:
        return {"success": False, "message": "无效的扭蛋池"}

    pool_cfg = GACHA_POOLS[pool]
    price = pool_cfg['price']
```

```python
@app.post("/api/pets/{pet_id}/rename")
async def rename_pet_by_id(pet_id: int, name: str = Form(...)):
    """给指定宠物重命名"""
    name = name.strip()
    if not name or len(name) > 20:
        return {"success": False, "message": "名字长度需在1-20个字符之间"}
    conn = get_db_connection()
    target = conn.execute("SELECT id FROM pet_collection WHERE id = ?", (pet_id,)).fetchone()
    if not target:
        conn.close()
        return {"success": False, "message": "宠物不存在"}
    conn.execute("UPDATE pet_collection SET name = ? WHERE id = ?", (name, pet_id))
    # 同步镜像（如果改的是激活宠物）
    active_id = get_active_pet_id(conn)
    if active_id == pet_id:
        sync_active_pet_mirror(conn)
    conn.commit()
    conn.close()
    return {"success": True, "message": f"新名字「{name}」已生效！", "name": name}
```

```javascript
async function loadPetCarousel() {
  const resp = await fetch('/api/pets');
  const data = await resp.json();
  const track = document.getElementById('carouselTrack');
  track.innerHTML = '';
  data.pets.forEach(pet => {
    const card = document.createElement('div');
    card.className = 'pet-card' + (pet.is_active ? ' active' : '');
    card.onclick = () => pet.is_active ? null : switchPet(pet.id);
    card.innerHTML = `
      <img src="${pet.image}" alt="${pet.name}">
      <div class="name">${pet.name}</div>
      <div class="stage">${pet.stage_name}</div>
    `;
    track.appendChild(card);
  });
  document.getElementById('petCarousel').style.display = data.count > 1 ? 'flex' : 'none';
}

function scrollCarousel(dir) {
  document.getElementById('carouselTrack').scrollBy({left: dir * 100, behavior: 'smooth'});
}

async function switchPet(petId) {
  if (!confirm('确认切换宠物吗？当前宠物的状态会被冻结保存。')) return;
  const formData = new FormData();
  formData.append('pet_id', petId);
  const resp = await fetch('/api/pets/switch', {method:'POST', body:formData});
  const data = await resp.json();
  if (data.success) {
    showToast(data.message);
    setTimeout(() => location.reload(), 1000);
  } else {
    showToast(data.message);
  }
}
```

## 关键设计决策记录

### 为什么用 `sync_active_pet_mirror()` 兼容层？
- 50+ 处 `WHERE id=1` 全部重写风险高、回归测试量大
- 兼容层让旧代码读 `pet.exp` 仍能拿到激活宠物的 exp（镜像同步）
- 新代码直接操作 `pet_collection`，写完后调用 `sync_active_pet_mirror()`
- 缺点：每次写操作多一次 UPDATE（性能可忽略，单用户场景）

### 为什么 `skin_id` 从 `parent_settings` 迁移到 `pet_collection`？
- 旧设计：所有龙共享一个皮肤（全局 current_skin）
- 新设计：每只宠物独立选皮（龙用 fire，猫用 default）
- 迁移：把 `parent_settings.current_skin` 写入 `pet_collection.skin_id`（仅第一只龙）

### 为什么同物种不可重复领养？
- 用户决策：避免收集爆炸，每物种唯一
- 简化数据：物种 ID 即可作为宠物身份标识
- 扭蛋：已领养的物种不参与抽选，避免重复

### 为什么冻结而非继续衰减？
- 用户决策：简单，切回来恢复原样
- 实现：`is_frozen=1` 的宠物调度器不处理
- 调度器只读取 `get_active_pet_row()`（自动过滤 frozen）

## 风险与对策

| 风险 | 对策 |
|---|---|
| 50+ 处 `WHERE id=1` 改造遗漏 | `sync_active_pet_mirror()` 兼容层兜底 |
| 数据迁移中途失败 | 备份在 `backups/homework_pet_pre_v33_*.db`，可回滚 |
| 皮肤系统与新物种冲突 | 新物种第一版仅支持 `default` 皮肤 |
| 前端调用量大 | 优先改 5 个核心接口，其余按需 |
| 扭蛋概率争议 | 概率明示在 UI，已领养的不参与（不重复） |
| AI 生图风格不一致 | Prompt 统一风格模板，人工筛选 |
| 生产 DB 体积增长 | 35 张图片压缩到 256×256，总体积 < 2MB |
| Railway 部署失败 | `requirements.txt` 不变，无新依赖 |
